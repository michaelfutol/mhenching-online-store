## Economics rule

Shopee source price is **not landed cost**. Before purchase approval, add:

1. actual checkout shipping after vouchers;
2. allocation of inbound freight across ordered units;
3. local packaging/label cost;
4. expected defect/return allowance when relevant;
5. any COD/delivery cost borne by Mhenching.

The app may show provisional economics for triage, but only actual purchase/receipt data becomes canonical cost.

## Ad-readiness rule

Do not permanently reuse marketplace seller photos/videos/descriptions. Once samples arrive:

1. QA the item;
2. photograph/video it ourselves;
3. create Mhenching title/copy;
4. show the real use case in a 6–15 second vertical demo;
5. publish only after price, quantity and fulfillment are verified.

## Suggested first order

Default to **3–5 units each**, not a case/carton. The purpose of the first buy is evidence, not inventory accumulation.
